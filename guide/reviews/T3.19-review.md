It also calls `--reset-values` "the same as the default behaviour, explicit". That is not exactly right. Helm's upgrade code has a special case: if the upgrade supplies no values at all (no `--set`, no `-f`) and the previous release had user-supplied values, Helm copies the previous release's values ("copying values from previous release").
