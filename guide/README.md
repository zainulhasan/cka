# CKA / CKAD Study Guide

Linux, then Kubernetes basics, then CKAD, then CKA, on Kubernetes v1.37. 76 lessons in four parts. Every lesson has concepts, a diagram, commands to produce fast, a worked example, common mistakes, three labs (easy, medium, break-fix), exam tips and a quick review.

Use the sidebar to pick a lesson. Start with the [conventions](00-conventions.md): they define the shell aliases, lab clusters and image pins every lesson uses. [Progress](PROGRESS.md) shows which lessons are written and reviewed.

This guide is a work in progress. Lessons marked "NEEDS-HUMAN" in the progress table passed most checks but still have one known error listed there. Outputs labelled "EXPECTED OUTPUT (not captured)" have not been run on a live cluster yet.

## How to move around
- The sidebar lists only the lessons that exist, with a count per part. Click one to read it.
- [Roadmap](ROADMAP.md) shows all 76 topics and which are written yet.
- Press `m` (or use the button at the top left) to hide the sidebar and read full width.
- Inside a lesson, the right-hand outline jumps between its sections.
